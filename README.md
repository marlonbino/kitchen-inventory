# Kitchen Inventory Management System

A complete kitchen inventory management system built with Django REST Framework backend and Vue 3 frontend.

## Project Structure

```
kitchen-inventory/
├── backend/          # Django REST Framework API
└── frontend/         # Vue 3 + Vite + Tailwind CSS
```

## Tech Stack

### Backend
- Django 4.2+
- Django REST Framework
- django-cors-headers
- python-decouple

### Frontend
- Vue 3 (Composition API)
- Vite
- Vue Router
- Pinia
- Tailwind CSS
- Axios

## Getting Started

### Backend Setup

See `backend/README.md` for detailed setup instructions.

### Frontend Setup

1. Navigate to frontend directory:
```bash
cd frontend
```

2. Install dependencies:
```bash
npm install
```

3. Run development server:
```bash
npm run dev
```

The frontend will be available at `http://localhost:5173`
